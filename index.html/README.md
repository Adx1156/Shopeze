# Shopez – E-commerce Website

A responsive e-commerce website built using HTML, CSS and JavaScript.

## Features
- Dynamic product fetching using Fetch API.
- Product search and filtering.
- New Arrivals section.
- Interactive shopping cart.
- Quantity management.
- Responsive design.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
